###### \# Retail Customer Classification Pipeline

###### 

###### \## Problem Statement

###### The objective of this project is to build an end-to-end machine learning pipeline to classify retail customers. Specifically, this Review 1 deliverable focuses on predicting whether a customer is a "Repeat Customer" based on their Recency and Monetary spending metrics derived from raw transaction data.

###### 

###### \## Dataset Description

###### The dataset is the "Online Retail" dataset, containing transactional records for a UK-based non-store online retail dataset. 

###### \* \*\*Target Variable:\*\* `Repeat\_Customer` (Binary: 1 if Frequency > 1, else 0)

###### \* \*\*Features Used:\*\* Engineered RFM metrics (Recency, Monetary) scaled using `StandardScaler`.
